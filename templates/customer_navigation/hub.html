このメニューの使い方 {% if section.key == 'products' %}

まず保管方法を選んで登録します。商品一覧で基本情報を、保管場所・作業履歴で現物の動きを確認できます。以前の台帳とまだ照合されていない商品は、どちらか一方にだけ表示される場合があります。

{% elif section.key == 'requests' %}

預け入れの申請 → 発送の報告 → 開花で受領 → 撮影・登録 → 出品内容の確認、の順に進みます。申請しただけでは受領・出品は完了しません。以前の依頼は履歴から確認できます。

{% elif section.key == 'money' %}

商品ごとの手残りは「料金・利益」、月ごとの内訳は「請求・資金記録」で確認します。売上や見込利益は、仕入れに使える残高とは分けて表示します。利用プランと現物の作業料も別の確認項目です。

{% elif section.key == 'documents' %}

書類を作成し、内容を確定して保存した後、送信先を確認して別の操作で開花へ送信します。プレビューは任意です。申請済みの商品は、追加する候補とは分けて確認できます。

{% elif section.key == 'support' %}

商品の承認や期限の連絡は「自分宛てのお知らせ」、全体の案内は「開花からのお知らせ」に届きます。問い合わせの返答は「問い合わせ・返信」で確認できます。ホームの表示項目はホーム上部から変更できます。

{% endif %}
