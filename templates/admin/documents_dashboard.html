書類管理

この画面では、クライアントから届いた依頼書、開花から業者へ送る書類、業者から返ってきた書類、最後にクライアントへ返す書類を、案件単位で確認できます。

書類履歴を見る 販売代行BOXへ

1. クライアントから受付

{{ document_counts.get('client_incoming', 0) }}件

クライアントが作成した見積り依頼書、買取依頼書をまずここで確認します。販売代行案件に紐づく書類の起点です。

  • 見積り依頼書
  • 買取依頼書
見積り依頼書: {{ document_type_counts.get('client_mitsumori', 0) }}件 買取依頼書: {{ document_type_counts.get('client_kaitori_request', 0) }}件

2. 開花から業者へ依頼

{{ document_counts.get('vendor_estimate', 0) }}件

ユーザーからの依頼内容を確認したら、開花名義で業者向け見積依頼書を作成します。

  • 業者向け見積依頼書

3. 業者から回答受領

{{ document_counts.get('vendor_statement', 0) }}件

業者買取明細書が届いてから、開花側で最終確認を行います。ここが済むまでユーザー向け買取明細書は確定しません。

  • 業者買取明細書

4. クライアントへ返送

{{ document_counts.get('client_outgoing', 0) }}件

確認が完了したら、ユーザー向け買取明細書や仕切書、計算書を発行し、クライアント画面へ反映します。

  • ユーザー向け買取明細書
  • 仕切書
  • オークション計算書
ユーザー向け買取明細書: {{ document_type_counts.get('client_invoice', 0) }}件 仕切書: {{ document_type_counts.get('shikiriosho', 0) }}件 オークション計算書: {{ document_type_counts.get('auction_keisan', 0) }}件
