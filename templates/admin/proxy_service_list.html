代行仕入れサービス管理

このページで、公開中・公開前・保存のみ・履歴をまとめて管理できます。ユーザー側に見える一覧もここから確認できます。

ユーザー側の公開一覧を確認 {% if can_create_more_auctions %} + 新規ページを作成 {% else %} {% endif %}
公開中 {{ current_auctions|length }}件 いま参加できるページ
公開前 {{ upcoming_auctions|length }}件 開始日時待ち
保存のみ {{ draft_auctions|length }}件 下書き・非公開
履歴 {{ history_auctions|length }}件 締切済みページ
公開枠 {{ active_auction_count }}/{{ max_auctions }} 公開中と公開前だけを集計

使い方

1. 新規ページを作成

まず「新規ページを作成」からオークション枠を追加します。

2. 商品を掲載

各ページの「管理・編集」から商品を載せ、価格や方式を設定します。

3. 公開または予約

非公開のまま保存もでき、必要なタイミングで今すぐ公開または日時予約できます。

4. 締切後に結果確認

履歴から結果を確認し、必要に応じてクライアント商品一覧へ反映します。
